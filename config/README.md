# 运行配置目录

首次在网页中保存“本机运行与节点策略”后，控制台会在此目录自动创建 `console.json`。

请通过网页维护该文件，不要将任务 JSON 放入此目录。

`video.json` 是视频旁路的版本控制默认配置：默认关闭，不会启动 MediaMTX、
GStreamer，也不会订阅 ROS 图像。当前目标车固定使用 Intel UHD 630 的
`/dev/dri/renderD128` 和 VAAPI H.264；四路输入只读订阅 front/back/left/right
的 `rgb8` 原始图像话题，sidecar 的 DDS 队列深度固定为 1，并将输出严格限为
15 FPS。视频配置只描述旁路所需的 ROS 话题与编码参数；物理 USB 端口及
v4l2loopback 映射由小车既有相机采集配置维护，Aletheia 不读取、不复制，也不
会抢占任何 `/dev/video*` 设备。

`ros_domain_id` 必须与小车相机节点所在 DDS 域一致；已验证车辆为 `66`。该值由
视频运行器显式传给原生 ROS 视频旁路进程，不能依赖 Supervisor 是否继承交互式
终端环境。旧版用户配置缺少该字段时，为兼容同一车型仍按 `66` 运行；其他车辆应
在启用视频前显式填写其实际域号。

网页离线 ZIP 会更新程序二进制，并在下一次启用视频前原子刷新其内置的私有视频 runtime，
但不会覆盖此目录中的运行配置。完整 DEB 也携带同一私有视频 runtime；在该 runtime 完成部署前，配置必须保持 `enabled: false`。完整 DEB
不会创建 Supervisor 或 systemd 服务。日常由“实时运行观测”页的“启用视频/关闭视频”
开关控制：关闭会立即回收本工具创建的 MediaMTX 与编码进程，且保存为下次启动仍关闭；首次
在网页启用时，若四路流均未选中，会启用这套已验证的默认四路配置。之后若维护人员只保留
部分流，该选择会被保留。启用才由普通账户运行的 `ry-aletheia` 持有该进程。退出、网页“安全退出”或离线升级也会
自动停止它。`ry-aletheia-video` 仅用于维护排障，不是日常启动步骤。
