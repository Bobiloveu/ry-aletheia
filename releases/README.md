# RY Aletheia 使用手册

RY Aletheia 是机器人小车的自动测试工具，用于管理测试用例、执行批量测试、检查运行依赖、记录地图轨迹，并生成可下载的测试报告。

工具在小车本机运行；测试人员只需使用浏览器访问小车页面，不需要联网。

## 选择安装包

`releases/` 目录中的文件用途如下：

| 文件 | 何时使用 |
| --- | --- |
| `ry-aletheia_<版本号>_amd64.deb` | 第一次安装到一台小车，或需要完整重装时。 |
| `ry-aletheia_<版本号>.zip` | 工具已经安装，只需更新到新版本时。 |
| `<版本号>-offline/` | 无网络且未预装 Foxglove Bridge 的小车：包含 Aletheia、Bridge 与一键离线安装入口。 |

首次安装请使用 `.deb`；后续更新请在网页内上传 `.zip`。不要解压 ZIP，也不要直接运行 ZIP 内文件。

## 第一次安装

1. 将 `.deb` 文件复制到小车。
2. 在小车上双击安装；如需终端安装，进入安装包所在目录后执行：

```bash
sudo dpkg -i ./ry-aletheia_<版本号>_amd64.deb
```

完整 DEB 已内置工具专用 Foxglove Bridge，推荐使用 `dpkg -i` 安装，避免系统中与本工具无关的 APT 未完成依赖阻塞流程。不要为安装本工具执行 `apt autoremove`。

3. 安装完成后，工具保持停止状态，不会开机自启。
4. 需要使用时，以安装工具的普通账户在小车终端执行：

```bash
ry-aletheia
```

5. 将电脑连接到小车 Wi-Fi，在浏览器打开：

```text
http://<小车IP>:8087
```

例如：`http://192.168.1.20:8087`。

## 启动与停止

工具不会开机自启。每次需要使用时，以普通账户在小车终端执行：

```bash
ry-aletheia
```

网页右上角的“安全退出”可停止工具；也可以在启动工具的终端按 `Ctrl+C`。关闭浏览器不会停止工具。停止后，再次执行上面的 `ry-aletheia` 即可启动。

启动终端会显示监听地址；也可在浏览器访问 `http://<小车IP>:8087` 确认工具已正常运行。

如需实时查看 CPU 占用，请执行：

```bash
ry-aletheia-status
```

终端会每秒刷新一次 CPU 百分比、内存占用和进程状态；按 `Ctrl+C` 退出查看。`100%` 表示占用一个逻辑 CPU 核心。

如果看到 `Address already in use`，表示工具已经在运行，无需重复启动。

## 测试操作流程

1. 打开“测试用例管理”，拖入任务 JSON 文件，或确认已有用例已显示。
2. 为用例填写易懂的场景别名，例如“电梯上行回归测试”。
3. 打开“运行配置”，在“测试依赖节点编排”中识别并配置本测试需要恢复的节点。
4. 回到“任务指挥台”，选择用例，设置执行轮次和轮次间隔。
5. 点击“开始自动化执行”。工具会自动检查运行依赖，准备完成后开始任务。
6. 在执行过程中查看本轮进度和执行记录。若出现停滞或失败，按页面提示处理；小车恢复到测试起点后可继续剩余轮次。
7. 打开“报告中心”查看、下载或删除测试报告。

报告内含每轮结果、地图、理想路线、虚拟墙和实际运行轨迹，可直接发给其他人员查看。

## 添加任务文件

推荐在网页“测试用例管理”直接拖入任务 JSON 文件。也可以将任务文件复制到以下目录后，在网页中刷新用例：

```text
/home/<普通账户>/ry_aletheia/tasks/
```

任务文件只支持 JSON 格式。建议在网页中保存场景别名，便于后续选择正确的测试用例。

## 更新工具

1. 将电脑连接到小车 Wi-Fi。
2. 打开“运行配置”。
3. 在“工具离线升级”中拖入 `ry-aletheia_<版本号>.zip`。
4. 确认升级并等待页面提示完成。

升级完成后工具会自动重启。已有任务、用例别名、配置、报告和地图轨迹不会丢失。

测试正在执行、正在终止或等待人工恢复时，不能升级；请先完成或终止当前测试。

## 卸载

如需移除工具，在小车终端执行：

```bash
sudo apt remove ry-aletheia
```

卸载会停止工具并移除启动服务，但会保留任务、配置和测试报告，以防测试证据丢失。

如确认不再保留这些数据，可在卸载后手工删除对应目录：

```bash
rm -rI /home/<普通账户>/ry_aletheia
```

将 `<普通账户>` 替换为实际账户名；命令会再次要求确认。执行删除前，请先备份需要保留的任务文件和测试报告。

## 无法访问网页时

1. 确认电脑和小车连接的是同一个 Wi-Fi。
2. 确认浏览器地址中的小车 IP 正确。
3. 在小车终端执行：

```bash
ry-aletheia
```

4. 如果提示端口已被占用，通常说明工具已在运行，请直接访问页面或先在原启动终端安全退出。
5. 仍无法访问时，联系维护人员，并提供启动终端输出与“工具日志”下载文件。
