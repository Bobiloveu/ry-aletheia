# PCD 投影压力测试 · 2026-10-10

测试使用用户指定的 `/opt/ry/data/maps/D_zone/lx3-nortk/map_1.pcd`，文件 87,462,400 字节，6,035,109 点，binary_compressed 编码。字段为 Label、Intensity、x、y、z，不含 RGB。源文件 SHA-256：`e9fd30dbc09562bf21670d7adec8cc72071c2ec265068e141e3055ed87de8d90`。所有输出放入独立临时目录，测试前后源文件哈希一致。

## 方法与结果

本机 Linux x86_64、Pixi 锁定 Python 环境；先完成一次高度分析，再连续转换 10 次。时间包含栅格化、去噪与 PGM/YAML 写入，不含上传、首次分析、PNG 编码或浏览器显示，不能视为车端端到端耗时。

参数：Z 3.961613082885742 至 5.311613082885742 米，分辨率 0.1 米，每格最少 1 点，去噪开启。输出 1741 × 5009 格。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 10 次转换中位耗时 | 1.210 秒 | 0.476 秒 |
| 转换耗时范围 | 1.153–1.259 秒 | 0.390–0.557 秒 |
| 首次高度分析 | 1.475 秒 | 1.226 秒 |
| 进程峰值 RSS | 506 MiB | 502 MiB |

重复转换约提速 2.54 倍，耗时减少约 61%。两版本 20 次输出 PGM 的 SHA-256 均为 `c694d8dd8a7c8a3888a5f6fb3a3e113124308eaf3e8fd6f7e385865775beec3a`。另在三个高度范围、每格阈值 1/2/3、去噪开关的五组参数下对比，PGM 和 YAML 均逐字节一致。

修正访问时间判断后，再完成 10 次转换，输出哈希仍相同。因同时有全量回归及桌面负载，转换中位耗时升至 0.795 秒。随后将两个版本在同一进程交替运行各 10 次，消除两批运行负载不同的影响：优化前中位 2.355 秒、优化后 0.755 秒，约提速 3.12 倍，20 份 PGM 哈希仍一致。绝对耗时随机器负载变化，应在目标车上复测。

同一地图在 0.15 米分辨率下，带相同 profiler 的三次对照中，转换从约 1.064 秒降至 0.327 秒；两版本输出哈希相同。主表采用不带 profiler 的结果。

## 优化与边界

- 复用已验证的 XYZ 解码结果，进程仅保留最近一个点云数组，最多 240 MB；文件身份、大小、修改时间与变更时间用于失效判断，小文件额外校验内容摘要。访问时间变化不会误判为内容变化。
- 按坐标列计算边界；每格最少 1 点时使用布尔占据栅格，避免分配整幅 int64 计数图。大于 1 点的阈值保留原计数语义。
- 保持 1600 万栅格和 1000 万输入点限制。这张地图按 0.05 米覆盖全范围约需 3490 万格，会明确拒绝；压力测试使用 0.1 米，不自动调整实施人员选择的分辨率或高度。
- 3D 源点云缓存由受控后台工作线程按需生成，显示全部有效点，不再做二次抽稀；保留真实 RGB/强度。沿用 1000 万输入点上限，线载荷最大 200 MB；投影仍使用完整有效点。旧抽样缓存首次查看会后台重新生成。

## 复现

从仓库根目录运行（只读源文件，输出写入新临时目录）：

```sh
env -u PYTHONPATH PYTHONNOUSERSITE=1 pixi run python scripts/benchmark-pcd-projection.py \
  /opt/ry/data/maps/D_zone/lx3-nortk/map_1.pcd \
  --resolution 0.1 --denoise --iterations 10
```

可用 `--z-min`、`--z-max` 指定人工选择的高度。未指定时采用候选高度供基准测试使用，不表示该高度已经现场验收。脚本输出每轮时间及包含源文件、参数、哈希、峰值内存的 JSON 报告。

2026-10-10 按用户要求移除 200 万点缓存与 25 万点显示抽样后，独立进程对同一源文件生成全量显示缓存：6,035,109 个有效点，120,702,180 字节，生成耗时 1.203 秒，进程峰值 RSS 720,556 KiB（约 704 MiB），无 swap。时间不含网络传输、浏览器解码或 GPU 上传；该结果是开发机单次测量，不能代表车端表现。

隔离 HTTP/真实浏览器验证确认载荷完整，旋转后 WebGL POINTS draw call 的 count 为 6,035,109，没有客户端抽稀。桌面、430 px 窗口、全屏、高度联动和选区显隐均保持同一画布和完整点数；源文件没有改写。全屏仅放大当前视图，不自动重设观察角度。测试不使用生产 8087、不启动 ROS、不编译或升级小车。
