# 已完成项目重新编辑

完成部署后，点击上方任一步骤即可回看；通过“修改此步骤”重新进入该步骤的编辑器。
进入编辑和未保存退出不提交项目变更，各项仍由原有保存按钮提交。项目、地图、标记、
任务线路及导出步骤的编辑器均保留；修改导致前置事实不足时，须先修正事实再重新校验。

原项目第一步只开放地图阶段流程，没有项目名称、任务模式更新接口，也未显示项目设置
面板。本次补上现有项目的名称及 `single/multi` 模式编辑。更新接口与消费者见
[部署契约](../../shared/contracts/deployment.md)。Backend 与 PC Web 受影响，Mobile 不消费。

保存设置保留项目 ID、创建时间、地图文件、实例、定位事实、组件、共享设备、任务线路
以及已有导出文件。名称规范化空白后须为 1–80 字符，模式只能是 `single` 或 `multi`。
实际变化清空预览确认标识，须重新编译校验；未变化的保存保留确认。历史任务编译按保存
后的模式选择 single/multi 编译器；固定任务线路也按该模式导出，遵守
[多任务分段限制](FIXED_MULTI_EXPORT_2026-10-13.md)，不改写其访问顺序或仓控动作。
客户端丢弃旧项目快照的预览响应；同一项目重新打开或重新进入编辑后，旧保存响应
不能覆盖新草稿或结束新的编辑会话。

浏览器验证使用当前已完成项目的临时副本，确认五个步骤的编辑器均可访问、进入编辑不写入
项目、名称和模式保存后可重载、其余项目事实保持一致，旧预览失效。修正了宽屏布局样式
重新显示隐藏的新建表单的问题。实际项目、现场地图及机器人运行目录未修改。

验证包括相关 Backend 检查、全部 Web 单元测试、parity、语法和浏览器检查。
本次未构建、打包、部署或重启已有服务。
