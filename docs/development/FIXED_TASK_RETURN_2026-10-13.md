# 固定线路节点、直接返程与预览核验

本文记录早期独立返程策略及当时的验证。后续已按“从哪来就从哪返回”修正为原路逆序返程，最新规则与验证见 [原路返程修正](RETURN_RETRACE_2026-10-13.md)。下文独立返程及绕过取货位置的描述不再代表当前行为。

固定线路导出的 `waypoint_id` 改为执行序号、方向、英文用途及可读位置名称；项目中的组件和过渡点 ID 保持不变。行为树文件继续保留英文动作名，所有引用同时更新。

编译器从与导出同源的编辑栅格及虚拟墙发现实际经过的窄通道、区域和门禁。窄通道写入长轴首末两个真实节点，入口停靠、出口采用组件通行速度。补入节点后重新检查新接近路径上的设施；轴线被障碍或虚拟墙阻断时拒绝编译，不能以区域外绕行代替穿越。

送货完成后独立生成返程：从最后访问位置经必要的已批准共享电梯连接回到起点，不反放取货线路、不重复仓控。单任务保持 `tasks/`，多任务保持公共去程、楼层去程、楼层返程、公共返程四个 `multi_tasks/` 文件。定位初始化按实际首个返程节点记录，完成动作只在回到起点时执行。

最终回到起点时，直接使用起点保存的完整位姿，朝向与出发时一致，不翻转 180°。
公共段按部署阶段角色命名：摆渡层为 `sub_outdoor_eguard[ _r ].json`，电梯大厅为
`indoor/<building>_<unit>[ _r ].json`。地图中的电梯组件不改变地图阶段角色。

实验预览增加“全部 / 去程 / 返程”。连线、节点、位置标记与列表一起筛选；列表来自实际编译节点，电梯呼梯、入梯、出梯与回到起点分别标识。切换方向不重新规划。带 `leg` 的执行块只显示实际有向路径；旧的无方向清单保留兼容回退。

## 验证

- Backend 相关检查：284 项通过；离线检查：109 项通过。
- 前端全量：603 项通过，Vite 构建通过；独立 Backend、Web 审查发现的问题均已修正并复查。
- 真实项目只读副本：18 个节点，窄通道去返各两个首末点；返程没有取货点或去程过渡点，最终回到起点。多任务四文件展开与预览节点一致，全部行为树引用有效。
- 浏览器核验：桌面、窄屏方向按钮无溢出；键盘切换有效；去程 5 个业务位置、返程 7 个实际节点；方向切换的 Worker 请求增量为 0，美化视图保持选中。
- 大图代表性测试：按用户提供 YAML 的真实图像引用读取约 3260 万栅格，10 m 样例路径及净空场构建约 0.35 s，峰值 RSS 约 162 MB。此结果不代表所有复杂绕行的最坏耗时。

初次全量 Backend 验证在实现前已收集新回归用例，出现 8 个预期失败，其他 1225 项通过；修正后所有受影响回归均已通过。上述最终通过数不将初次失败结果描述为全量通过。

## 构建复查

产物版本为 `2.8.1-shm`，升级 ZIP 与首次安装 DEB 位于 `releases/2.8.1-shm/`。包检查发现原有默认视频配置被映射为目录，已改为先暂存标准文件名 `video.json`，再映射到 `config/`；ROS、ShmSDK 两种输入及成功、失败清理场景都有实际脚本回归覆盖。

交付前检查签名、SHA256SUMS、ZIP/DEB 二进制一致性、包内 Backend 字节码与当前源码一致性、Web 资源、ShmSDK 配置及惰性 `--self-check`。真实项目和来源地图指纹保持不变；未部署、重启既有服务或调用机器人运行接口。

## 范围

净空场与 A* 仅用于离线设施节点发现，真实车辆仍由 Nav2 规划执行；不修改导航配置，也不等同于机器人足迹碰撞验证。搜索超过 25 万扩展节点或设施约束无法收敛时明确拒绝预览。返程只使用任务实际经过地图中唯一有效的同楼栋单元物理电梯连接。

Existing 消费者为 Backend、PC Web 与机器人任务文件读取；Mobile 不消费部署预览。本次更新部署契约，无 Mobile 工具链变更。
