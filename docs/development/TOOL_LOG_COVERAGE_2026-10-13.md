# 工具日志功能覆盖检查

现有入口仍为“工具日志”。本次把接口操作、实际后台结果和浏览器本地失败统一接入现有 JSONL、独立错误文件和诊断包；不采集机器人日志正文。

## 功能覆盖

| 功能 | 记录边界及结果 |
| --- | --- |
| 项目、名称、单/多任务点模式、地图阶段顺序 | 写接口开始/结果、返回项目编号、拒绝原因、耗时；损坏项目跳过/恢复、持久化迁移和自动补线 |
| 地图导入、绑定、组件、过渡点、虚拟墙、擦除、定位配置 | 所有新增/修改/删除接口统一记录；错误及拓扑检查提示进入日志 |
| 线路创建、保存、选择、删除、编译、预览、实验包下载 | 操作与返回编号、编译 errors/warnings、导出结果；无完整地图/任务正文 |
| 点云分析、投影、精细数据读取、确认导入 | 后台启动、修订号、成功/失败/取消、过期结果丢弃、启动时发现中断作业 |
| 建图 | 准备、启动、停止、保存、放弃、进程退出、地图缓存失败与恢复 |
| 用例上传、导入、管理、导出、删除 | 接口操作与拒绝原因；列表发现损坏用例也记录校验问题 |
| 单轮、多轮、多任务点测试 | 下发、轮次终态、失败/阻断、取消、人工恢复、整体终态 |
| 部署验收 | 创建、启动、取消、等待恢复的状态变化、报告与失败堆栈；修正 logger 命名空间 |
| 场景方案、文件浏览/读取、激活、恢复、Supervisor | 操作、后台阶段与终态、实际进程命令结果；不记录认证命令 |
| 手动控制、急停、重定位、地图标记导航 | 控制权/运动边沿、停止、超时、安全拒绝、自动取消原因、实际导航失败与恢复 |
| 车辆执行状态、定位、轨迹证据 | 订阅/采样故障与恢复、关闭异常、轨迹收尾摘要 |
| 实时观测、地图、点云/位姿/代价地图 | 沿用运行时日志与性能状态变化；浏览器 ERROR 进入独立错误日志 |
| 视频 | 沿用启停、输入/网关异常、配置失效和 `video-runtime.log`；接口操作补充统一关联编号 |
| 自动/手动诊断录包 | 开始、截止、停止、收尾审查、失败与异常堆栈 |
| 报告查看、原生报告、下载、删除、归档/迁移 | 读取/导出操作、归档结果与错误、关联报告编号 |
| 机器人日志源、文件查询、下载、实时跟随 | 写操作、读取失败、下载/跟随终态、HTTP 200 后子进程/文件读取失败；无日志正文 |
| 运行配置、车辆软件资产、自启、离线升级、安全退出 | 保存/校验/拒绝/结果；资产可用性变化；自启降级原因；升级检查/替换结果；配置/场景/用例注册表读取回退及恢复 |
| 浏览器入口、脚本/资源、HTTP/XHR、未处理 Promise | 所有传统/Vite/移动 Web 入口提前安装诊断；捕获异常、加载失败和请求失败 |
| 地图美化、绘制、路径规划、轨迹/点云解码、图片导出 | 被局部 catch 或 Worker 阻止冒泡的失败显式上报；关键本地处理完成记录 |
| 工具日志查询、独立错误流、文件清单、诊断包 | 保留既有接口；下载操作可查；正常日志轮询和上报端点不制造自循环 |

HTTP 层不读取或复制请求正文来写日志；返回结果仅选取白名单对象编号。异步记录用 project/job/revision/run/attempt/archive/report 等既有编号关联实际工作。

## 排障方式

1. 重现问题后进入“工具日志”，按时间查看相关功能的开始与结果。
2. 接口事件的 `request=…` 与响应 `X-Request-ID` 一致；同一请求中的模块日志具有相同可选上下文。
3. ERROR/CRITICAL 可切换“错误”单独查看；业务校验拒绝和警告保留在“全部”中。
4. 下载完整诊断包会包含工具日志、轮转历史与受控观测/视频子进程日志。完整异常堆栈仍可展开查看。

## 记录预算与兼容性

- 高频成功轮询、摇杆 vector/command、控制/观测心跳不逐次写入；控制器仍记录运动开始/停止与故障/恢复，不减少安全重试。
- 同一读取/高频端点的重复故障 30 秒内合并，恢复立即记录；显式修改操作保留逐次记录。
- 浏览器重复事件 30 秒合并、每分钟最多 60 次、最多 2 个在途上报；不积压、不重试上报失败；Backend 也限制预算和状态数量。
- URL 凭据/查询、常见敏感键值、命令超时中的完整 argv、data/blob 内容会清理；不记录输入正文、帧或点云。
- 必填 `time/level/source/message`、可选 `exception` 不变，新增上下文字段可选。Flutter 现有解析忽略未知字段，继续读取原接口；Flutter 本机反馈日志仍保持原本独立所有权。
- 事件卡片删除了左侧彩色描边，等级仍以文字颜色区分；桌面/窄屏、深浅主题检查通过。

## 验证证据

- `tests/test_tool_audit.py`、`tests/test_tool_logging_http.py`：格式/兼容、脱敏、实际私有 HTTP 写操作与读取、关联编号、语义错误/警告、高频静默/恢复、上报校验/预算、错误文件分流。
- `tests/test_async_tool_logging.py`：异步启动/终态/异常、验收恢复等待去重。
- `tests/test_backend_lifecycle_logging.py`、`tests/test_backend_diagnostic_edges.py`：生命周期、自动取消、可用性边沿、不减少 STOP/急停重试。
- `tests/test_deployment_diagnostics.py`、`tests/test_config_fallback_diagnostics.py`：落盘后再记录迁移/自动补线成功；损坏项目与配置回退去重、恢复、并发安全和缓存容量回收。
- Web reporter/HTTP/地图 Worker/路线 Worker 等回归与完整 `scripts/test-web.sh`。
- 私有 Chromium QA：桌面 1440×1100、窄屏 390×844，深浅主题、错误筛选；早期异常/请求失败/局部 Worker 失败/未处理 Promise 各上报一次；上报接口故意返回 500 仍无循环。证据目录 `/tmp/ry-tool-log-qa/`。
- 测试默认项目和日志目录都重定向至临时目录；未操作运行中的机器人、ROS、8087/5173 服务或现场地图。

后台源代码改动需要工具重新启动后生效；此次检查不重启现场运行实例。

最终结果：Web 713 项检查、页面契约检查和 Vite 构建通过；Backend 最终相关回归 710 项通过（3 项既有 TestCase 收集警告）。此前完整 Backend 检查为 1390 通过、2 个旧断言失败：多线路终末定位契约文本和导航异常日志等级；两个断言已同步当前事实，并纳入最终通过的回归。长耗时路线编译缓存压力测试已在完整检查中通过，未重复运行。
