# 实验预览完整节点清单修正

用户反馈：侧栏列出返程窄通道，却遗漏去程窄通道。

原因是 `previewTaskItems` 在固定线路去程使用人工配置的业务步骤摘要，返程使用实际编译节点；
自动生成的乘梯、通道进入/离开等去程节点因此未出现在侧栏。编译任务本身包含这些节点。

本次仅修改 Web 展示，去返程统一按实际编译节点逐条列出，保留原始顺序、地图归属、
通行角色和速度说明。目标取送货动作按每次访问依次附加，重复经过同一位置不合并。
手动过渡点沿用既有可区分名称。只有缺少实际节点的历史摘要预览继续使用原摘要回退。
顶部数量同步显示实际去程/返程节点数，不再把人工步骤数与实际返程节点数混在一起。
`backward` 在当前编译器的电梯出梯节点上显示为“出梯速度”，避免去程节点被误标“返程”。
