# 多任务独立楼层线路补全

目标：保存地图组件不结束编辑；目标点可区分；同项目多条线路可编辑、完整预览并输出既有 multi_tasks 格式。

边界：保持已有 Backend 编译与机器人控制所有权，不迁移目录、不改写现场项目和运行时。single 仍编译选中线路；multi 编译全部已保存线路。公共段必须语义一致，不能静默覆盖。每条楼层线路以唯一送货目标结束。新增目标的自动线路策略以本次用户澄清为准。

- [x] Web 编辑会话：写保存后仍停留、显式结束才返回的回归，再修复会话生命周期。
- [x] 目标点识别：门牌号、未填门牌的稳定可读编号共用到画布、选择列表、流程卡和预览；覆盖同图重名目标。
- [x] Backend 汇总：新增多条固定线路编译测试，复用单线路权威编译；合并公共段、XML、定位清单，拒绝冲突，分别导出各户 floor 去返文件。清单记录每条线路的实际节点范围；更新 Backend/Web 消费契约与缓存代码摘要。
- [x] Web 多线路：保留保存列表及新线路草稿，切换编辑、全部/单条实验预览、配置图使用所属线路节点。覆盖不跨线路误连和动作归属。
- [x] 最小相关与完整 Backend/Web 检查、独立审查、私有项目副本浏览器/ZIP 端到端验证。不触碰现场服务或构建安装包。测试收集触发项目自动补齐的隔离遗漏已纠正并记录于验证报告。
