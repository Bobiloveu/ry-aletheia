# 历史设计与计划记录

`specs/` 与 `plans/` 保存特定日期的设计讨论、实施计划和当时的验证上下文，用于追溯决策；它们不是当前运行时或协议的事实来源，因此保留原始语言和时间语义，不做事后改写。

日常维护请使用以下当前文档：

- 开发角色、操作系统限制和命令：[开发 Profile](../development/PROFILES.md)
- 模块边界：[架构文档](../architecture/README.md)
- 跨端接口：[共享契约](../../shared/contracts/README.md)
- 运行时、部署和机器人事实：[PROJECT_OVERVIEW.md](../../PROJECT_OVERVIEW.md)
- 移动端源码与工作流：[mobile/README.md](../../mobile/README.md)

如需根据历史方案恢复或续做某项工作，先确认方案是否仍适用于当前代码、契约和已发布渲染主线；不能把历史中的 Planned 事项视为当前 Existing 能力。
