# 部署链路全面自检

用户目标：完成后全面自检，避免类似阶段目录、模式和朝向错误再次遗漏。

验收范围为部署 Backend、Web 编辑/预览/导出和安装产物。保留已批准的机器人控制边界；
不改真实项目、地图或运行配置，不重启 8087/5173、不启动 ROS/车辆，不提交脏工作区。

必须验证：完整 Backend、Web、离线测试；项目完成后重编辑；单/多任务与阶段目录；
起点返程同朝向；真实通道首末点；直接返程；预览/实际 JSON/缓存/安装包一致；
组件编辑异步归属、首次旋转、光标与地图美化；安装权限不超出受控节点。

独立审查已复现的修复要求：

1. 电梯放置事务必须绑定打开时的项目、地图、坐标和草稿身份；切图、切项目、取消重开后旧异步响应不能放置到新上下文或关闭新弹窗。
2. 任务信息和流程保存只能更新原项目、原编辑上下文；预览等待期间线路变脏后，旧预览不得打开或保留为有效。
3. 公共源地图实例的楼栋单元归属必须与绑定一致；全局摆渡实例仍保持全局归属。
4. 读取栅格时必须验证源 YAML 标定与项目资产一致，不能在错误标定上导出任务。
5. 电梯进出腿不能静默忽略相交设施。超出现有批准电梯执行语义的设施重叠必须明确拒绝编译，不能自行改变入梯/出梯行为树时序。
6. 日志发现的 Supervisor 节点只获得日志读取规则，不得扩大 start/restart 控制白名单。

对每项先观察失败测试，再实施最小修复，独立复查。发现其他确定问题继续处理。
源码冻结后运行最终完整验证；新构建使用 2.8.3 ShmSDK ZIP+DEB，保留既有发布目录，
检查签名、哈希、冻结代码/全部资源、DEB 内容和惰性启动自检。只声明实际验证范围，不声称已上车实测。
