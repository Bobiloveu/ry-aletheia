# 固定线路实际节点与直接返程

用户要求：导出的点名可读；窄通道必须有实际首末节点；楼上送货后乘梯直接回起点，不反放取货绕行；实验预览可查看返程；修复后构建并复查。

- 项目 single/multi 模式继续决定 tasks/ 与 multi_tasks/，多任务包保持四段及既有五字段格式。
- JSON waypoint_id 使用有序、唯一、可读的用途名称，英文动作命名保留。项目内组件 ID 不改写。
- 真实地图栅格（含擦除、补墙、虚拟墙）决定路径经过的窄通道，自动补齐长轴两端，复用执行链速度语义。未经过的组件不加入任务。
- 返程从最后访问位置经已批准的共享电梯连接回起点；不再次访问取货点或去程过渡点。不得猜测未批准切图连接，所有返程腿校验可达性，完成动作只执行一次。
- 预览提供全部、去程、返程选择，连线、节点、列表一致，返程顺序来自实际编译结果。
- Existing 消费者：Backend 编译、PC Web 预览、机器人任务 JSON/行为树；Mobile 不消费部署预览。保留运行时字段、控制边界和已批准行为树端口。
- 不修改真实 deployments/1，不启动 ROS/车辆、不重启现有服务，不提交脏工作区。
- 构建默认 2.8.1 ShmSDK 升级 ZIP 与首次安装 DEB，用户后续选择优先。测试、产物清单、校验和与包内容复查后才完成。
